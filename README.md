# Загрузка выписки ИНН

Утилита для автоматического заполнения формы получения сведений об ИНН на сайте ФНС России.

Программа написана на Go с использованием Playwright. Предназначена для запуска из 1С и автоматического заполнения веб-формы ФНС на основании данных физического лица, переданных через JSON-файл.

## 1. Возможности

- Получение данных из JSON-файла.
- Автоматическое открытие сайта ФНС.
- Обработка экрана согласия в соответствии с установленным порядком работы.
- Автоматическое заполнение персональных данных.
- Заполнение сведений о документе, удостоверяющем личность.
- Возможность скачать PDF-документ.
- Сохранение загруженных файлов в каталог пользователя.
- Автоматическое открытие скачанного PDF.

**Важно:** программа не нажимает кнопку отправки запроса на получение ИНН. После заполнения формы пользователь самостоятельно проверяет данные и выполняет необходимые действия.

Подтверждение согласия на сайте ФНС должно соответствовать фактическим полномочиям и установленному порядку обработки персональных данных.

## 2. Используемые технологии

- Go
- Playwright Go `v0.6100.0`
- Windows

Основная библиотека:

```powershell
go get github.com/mxschmitt/playwright-go@v0.6100.0
```

## 3. Структура проекта

Исходный проект:

```text
.../
│
├── go.mod
├── go.sum
├── main.go
└── ...
```

Готовый переносимый комплект:

```text
.../
│
├── downloading-the-INN-extract.exe
│
└── playwright/
    │
    ├── driver/
    │   ├── node.exe
    │   └── package/
```

Программа определяет расположение драйвера и браузера относительно собственного EXE-файла.

Переменные окружения:

```text
PLAYWRIGHT_DRIVER_PATH
```

Они должны указывать на каталоги `playwright/driver` соответственно.

## 4. Подготовка окружения разработчика

Для сборки потребуется установленный Go.

Проверка версии:

```powershell
go version
```

Переходим в каталог исходного проекта:

```powershell
cd C:\Projects\...
```

Загружаем зависимости:

```powershell
go mod download
```

## 5. Подготовка переносимого комплекта Playwright

Создаём каталоги:

```powershell
$root = "C:\...\playwright"

New-Item -ItemType Directory -Force "$root\driver"
```

Устанавливаем пути для Playwright:

```powershell
$env:PLAYWRIGHT_DRIVER_PATH = "$root\driver"
```

Устанавливаем необходимые компоненты:

```powershell
go run github.com/mxschmitt/playwright-go/cmd/playwright@v0.6100.0 install chromium
```

После установки необходимо проверить, что в каталоге драйвера находятся `node.exe` и `package`.

**Примечание:** установку компонентов необходимо выполнять с той же версией Playwright Go, которая используется приложением.

## 6. Компиляция приложения

Создаём каталог комплекта:

```powershell
New-Item -ItemType Directory -Force "C:\..."
```

Собираем приложение:

```powershell
go build -o "C:\...\downloading-the-INN-extract.exe" .
```

## 7. Формат входных данных

Программа принимает путь к JSON-файлу первым аргументом командной строки.

Пример `request.json`:

```json
{
  "lastName": "Иванов",
  "firstName": "Иван",
  "middleName": "Иванович",
  "birthDate": "1985-05-20",
  "documentType": "21",
  "documentNumber": "4510123456",
  "documentDate": "2010-06-15"
}
```

Описание параметров:

| Параметр | Описание |
|---|---|
| `lastName` | Фамилия |
| `firstName` | Имя |
| `middleName` | Отчество |
| `birthDate` | Дата рождения |
| `documentType` | Код вида документа |
| `documentNumber` | Серия и номер документа |
| `documentDate` | Дата выдачи документа |

Даты передаются в формате `YYYY-MM-DD`.

Для паспорта гражданина РФ используется код документа `21`.

## 8. Проверка запуска

Запуск из PowerShell:

```powershell
C:...\downloading-the-INN-extract.exe C:\INN-Helper\request.json
```

При успешном запуске программа:

1. Загружает данные из JSON.
2. Запускает Playwright.
3. Открывает Chrome.
4. Переходит на сайт ФНС.
5. Обрабатывает экран согласия.
6. Заполняет форму.
7. Оставляет браузер открытым для пользователя.

## 9. Развертывание на новом Windows Server

Переносимый комплект не требует установки Go, Node.js на сервер.

Алгоритм развертывания:

1. Подготовить комплект на компьютере разработчика.
2. Проверить работоспособность EXE.
3. Скопировать всю папку на сервер.
4. Предоставить пользователям права чтения и выполнения файлов.
5. Проверить запуск от имени обычного пользователя Windows.

Все пользователи одного сервера могут использовать общий каталог с драйвером.

При этом каждому пользователю необходима собственная интерактивная сессия Windows, поскольку браузер запускается в видимом режиме.

Для работы нескольких пользователей одновременно следует создавать отдельный JSON-файл для каждого запуска, чтобы данные разных запусков не перезаписывали друг друга.

Каталог с компонентами Playwright должен быть доступен пользователям для чтения и выполнения. Запись в него обычным пользователям не требуется.

## 10. Скачивание PDF

Загруженные файлы сохраняются в каталоге:

```text
%USERPROFILE%\Downloads\Выписки ИНН\
```

После успешного сохранения PDF открывается стандартной программой Windows для просмотра PDF-документов.

## 12. Особенности эксплуатации

- Не удалять каталог `playwright`.
- Не перемещать EXE отдельно от каталога `playwright`.
- Для работы браузера необходима интерактивная пользовательская сессия Windows.
- Не запускать несколько процессов с одним и тем же входным JSON-файлом.
